# 목표 순위와 완료 기준

**미래 목표이며 완료 목록·확정 일정·품질 보장이 아니다.** 1·2순위는 사용자가 제시한 목표다. 3·4순위는 레퍼런스 비교 뒤 추천한 방향을 이번 문서에 정리한 것이다. 구현 착수·학습·비용 승인을 뜻하지 않는다.

## 1순위 · 맥락 기반 2D → 새로운 3D 장면

입체 가능 요소는 독립적인 새 3D component로 생성하고, 나머지는 주변 환경·공간 구성에 활용한다. 단순 깊이 돌출이 아니라 장면을 먼저 추론하는 방향이다.

완료 기준 제안:
- 객체·환경·여백의 역할과 객체 간 앞뒤·크기·접촉 관계를 기록한다.
- 원본 시점으로 돌아와 실루엣·배치·가림 순서를 비교한다.
- 가려진 면과 배경은 생성 가설임을 표시하고 실패 사례를 남긴다.
- 작은 장면부터 전체 경로를 실제 실행한다. 어댑터·CLI 검사만으로 완료 처리하지 않는다.

현재: 상대 깊이 2.5D 기준선과 미실행 GPU 연결 코드만 있다. 구성요소의 전역 맥락 추론과 완전한 장면 생성은 미완료다.

## 2순위 · 자연스러운 설정 자동 결정

입력과 장면에 맞는 점 배분·크기·표현 깊이 등 설정을 자동 선택해 기본 감상에 불필요한 수동 조정을 줄인다. 원본 색 유지 원칙은 자동 보정으로 대체하지 않는다.

완료 기준 제안:
- 고정 기본값과 자동 설정을 같은 입력·카메라·점 예산 조건에서 비교한다.
- 회화와 사진을 나눠 실패·과한 보정·구조 손실을 기록한다.
- 자연스러움 평가와 구조·색·성능 검사를 구분한다.
- 데이터 학습이 필요한지 먼저 판단한다. 학습 대상·데이터·권리·방식·비용은 별도 결정한다.

현재: 기존 자동 화질 기능은 기기 부하 대응이다. 자연스러운 설정을 학습한 시스템은 아니다. 별도 자동 맞춤 초안도 통계 휴리스틱이며 이 저장소의 검증 완료 기능으로 취급하지 않는다.

## 3순위 · 원작 충실도 검증과 선택적 부분 수정

자동 생성의 실패만 최소 수정한다. 매번 모든 설정을 사용자가 만지게 하자는 목표가 아니다.

완료 기준 제안:
- 원본 시점 비교와 주요 객체의 실루엣·상대 위치·가림 순서 검사를 제공한다.
- 객체별 재생성·위치/크기/방향 수정, 만족한 부분 고정과 되돌리기를 제공한다.
- 수정하지 않은 요소의 의도치 않은 변경을 점검한다.
- 원본 근거 영역과 새로 생성한 영역을 구분한다. 검증하지 않은 confidence를 정확도 확률처럼 보이지 않는다.

현재: 이름 변경·요소 선택은 이 교정 기능의 완성을 뜻하지 않는다. **기초 검증은 1순위부터 시작**하며 3순위에서 사용자용 검수·교정으로 발전시킨다.

## 4순위 · 안정적인 구조 보존형 3D 점묘 감상

실제 표면에 점을 배치하고 시점·확대 변화에서도 윤곽·형태·색과 대상의 정체성을 보존하는 표현을 검토한다. 기존 밀집도 슬라이더나 자유 회전만으로 달성된 목표가 아니다.

완료 기준 제안:
- 원래 시점·측면·뒷면이 드러나는 고정 검수 경로를 둔다.
- 표면 점 유지·가림·경계·빈틈·세부 수준 전환을 점검한다.
- 지각 품질, 원작 구도 정합성, 구조적 개연성을 각각 기록한다.
- 제품이 지원할 시점 범위를 밝히고, 실제 PC·모바일에서 로딩·프레임률·메모리를 측정한다.

현재: 일부 점 버퍼·예산·재로딩 검사는 있지만 다수 이미지의 감상 품질과 모바일 실기기는 미검증이다. 구조 보존 점묘의 효과는 선행 서비스가 대신 검증해 주지 않는 별도 제품·연구 가설이다.

## 실행 순서와 평가 원칙

대표 작품을 무작정 늘리기보다 인물·군중·산수처럼 다른 유형의 작은 평가셋부터 검토한다. 실제 입력·권리·분할·시드·시점·점 예산을 확정한 뒤 측정하고, 통제된 합성 검사와 실제 감상 평가를 혼합하지 않는다. 사진·회화의 숨은 면에 정답이 없다면 3D 정확도를 주장하지 않는다.

생성 실패, 설정 실패, 점묘 표현 실패를 나눠 기록한다. 초기에는 승인된 일회성 환경과 저장된 장면의 웹 재생을 검토하며 상시 GPU 서버는 전제하지 않는다. 사진 전송·새 학습·설치·비용 발생은 별도 승인 대상이다.
