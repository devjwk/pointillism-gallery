# 점 밀집도

메인 갤러리의 **기본 · 점 → 점 밀집도**에서 조절한다.

- **100%:** 밀집도에 의한 추가 변위가 0이다. 기존 이미지 형태와 배치를 유지한다.
- **낮은 값:** 같은 점들이 원래 형태 주변으로 조금씩 퍼진다. 0%도 점을 삭제하는 설정이 아니라 국소 흩어짐이 가장 큰 상태다.
- **점 개수와 별개:** 밀집도 입력은 점을 다시 샘플링하거나 점 예산을 바꾸지 않는다. 기존 자동 화질 조절이나 다른 설정에 의한 점 수 변경은 별개다.
- **부드러운 변경:** 목표 밀집도까지 프레임마다 보간한다. 모인 상태의 작품에 적용하며, 전체 흩어짐 연출과 제목 글자에는 추가 적용하지 않는다.

## 위치 처리

각 점의 기존 phase·noise를 재사용해 시간에 따라 바뀌지 않는 방향을 만든다. 밀집도 값을 움직일 때마다 난수를 다시 뽑지 않으므로 흔들리거나 매번 다른 위치로 재배치되지 않는다. 밀집도에 의한 추가 변위만 보면 같은 값으로 돌아왔을 때 같은 배치로 복원된다. 기존 작품의 작은 모션·커서 반응·시점 변화는 별개다.

화면에 맞춘 이미지의 짧은 변을 기준으로 최대 가로·세로 변위는 각각 12%, 깊이 변위는 4.2% 이내다. 낮은 값에서도 원래 형태 주변에 머무는 표현 효과이며, 전체 화면으로 흩어지는 버튼을 대체하지 않는다.

GPU 셰이더와 CPU 위치 스냅샷에 같은 변위 항을 반영한다. 따라서 피사체 선택과 작품 전환도 새 위치를 기준으로 계산한다. 전환의 출발 위치에 이미 담긴 흩어짐을 두 번 더하지 않도록 추가 변위에 전환 보간값을 곱한다.

이 기능은 **감상용 표현 설정**이다. 메쉬 재구성, 표면 샘플링 알고리즘, 뒷면 생성 또는 지각 품질 개선을 입증하는 기능이 아니다. 별도 알고리즘 검증 도구의 좌표와 측정 결과는 변경하지 않는다.

## 검사 범위

회전 변경까지의 35개 JS 검사에 밀집도 검사 8개를 추가했다. 검사 항목은 다음과 같다.

- 밀집도 상·하한, 단조적인 흩어짐 크기와 축별 범위
- 같은 phase·noise의 반복 결과, 100% 복원과 점 배열·목표점 보존
- 전환 시작점의 이중 변위 방지 및 보간 중 위치 항
- 전체 흩어짐과 제목에서 추가 효과 제외
- 슬라이더가 재샘플링을 호출하지 않는지 확인
- CPU·GLSL의 밀집도 수식과 uniform 연결
- 프레임 보간의 정확한 종점 도달 및 이후 유휴 상태

Node 검사는 실제 GPU 수치 일치를 실행하는 검사가 아니다. 브라우저의 셰이더 컴파일과 화면 비교는 별도 확인이 필요하다.

로컬 Chrome에서는 100% → 0% → 50% → 100%를 조절하며 셰이더 연결 성공과 GPU 오류 0을 확인했다. 100% 복원 시 추가 변위 uniform도 정확히 0으로 돌아왔다. 당시 자동 화질이 선택한 총 12,330점을 유지했고, 목표점 배열·분석 캐시·전환 시각도 바뀌지 않았다. 이는 해당 조건의 동작 검사이며 지각 품질이나 성능 우수성을 뜻하지 않는다. 개인 업로드 사진은 사용하지 않았다.

50% 상태에서 다른 작품으로 전환해도 설정이 유지됐고, 전환 후 12,330개 CPU 위치가 모두 유한했다. 화면 좌표 기반 피사체 선택 함수도 유효한 구성요소를 반환했다. 이는 연결 동작 확인이며 선택 정확도에 대한 통계적 검증은 아니다.
