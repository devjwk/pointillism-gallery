# 원본 색을 기본으로 표시하기

## 수정한 문제

이전 렌더러는 어두운 회화의 선을 밝은 점으로 보이게 하는 표현에 맞춰져 있었습니다. 여러 작품 프리셋의 명암 반전, RGB 최대 채널 정규화, 어두운 색의 흰색 대체, 강한 색 보정·채도가 원본과 다른 첫 화면을 만들었습니다. 반전 버튼만 끄는 것으로는 해결되지 않았습니다.

## 새 기본값과 조작

- 작품 선택과 새 이미지 업로드 시 색 반전 꺼짐, RGB 반영 1, 채도 1, 색 보정 0, 번짐 0, 초점 흐림 0, RGB 분리 0으로 시작합니다. 선 분석 보기 역시 꺼집니다.
- `원본 색 복원`은 위 표시 설정과 점 RGB를 복원합니다. 점 수·밀집도·기본 점 좌표·깊이·캐시를 다시 만들지 않습니다. 선택한 밝은/어두운 배경은 유지합니다.
- `색 반전`은 표시 셰이더에서 RGB를 반전하는 선택 효과입니다. 점 배치나 깊이는 바뀌지 않습니다. `깊이 반전`은 별도의 기존 기능입니다.
- 기본 뷰어 배경은 밝은 중립 회색입니다. 검은 먹선이 배경에 묻히지 않도록 하며 `배경` 버튼으로 기존 어두운 배경을 선택할 수 있습니다. 사이드바의 어두운 UI는 유지합니다.
- `점 배치 대비·감마`는 중요도 계산용입니다. 원본 RGB의 밝기를 바꾸는 노출 조절이 아닙니다.

## 데이터 경로 분리

1. `map.lum`은 회전된 원본 밝기, `map.rgb`는 원본 RGB 지도입니다. RGB가 없을 때도 원본 회색 값을 사용합니다.
2. 선·디테일·대비·감마와 `samplingInvert`는 별도 `samplingLum`과 `dens`에만 사용합니다. 정보가 없는 완전한 검정 입력에서는 균일한 양의 중요도를 사용해 빈 점 배열과 NaN을 피합니다.
3. 깊이의 가이드 필터·명암·필치 부조는 반전된 중요도가 아닌 원본 밝기를 기준으로 계산합니다. 기존 AI 깊이 모델의 입력 역시 원본 이미지입니다.
4. 점 RGB는 기본적으로 지도 바이트를 255로 나눈 값입니다. 최대 채널로 나누거나 검정을 흰색으로 치환하지 않습니다. 색 보정은 사용자가 켰을 때만 적용합니다.
5. 셰이더의 색 반영 1·채도 1은 중립값입니다. 기본 점의 불투명도와 크기를 밝기와 다시 곱하지 않아 어두운 점이 희미해지는 현상을 줄입니다.

**프리셋 호환성:** 기존 `catalog.js`와 원본·지도 파일은 바꾸지 않았습니다. 예전 `tune.invertTone` 값은 이제 먹선 점 배치의 극성인 `samplingInvert`로만 해석합니다. 화면 색 반전 기본값으로는 사용하지 않습니다. 런타임 표시 기본값이 예전 데이터의 색상 프리셋보다 우선합니다.

이미지 업로드에서 완전한 검정을 브라우저 읽기 실패로 오인하던 검사도 제거했습니다. 투명 PNG는 흰 바탕에 합성합니다.

## 실제 검증

- **JavaScript 자동 검사 109개 통과:** 기존 로더·회전·밀집도 검사와 원본 RGB, 회색 fallback, 좌표 경계, 10개 프리셋, 업로드 초기화, 표시 반전/깊이 분리, 완전한 검정 입력을 포함합니다.
- **실제 WebGL 48건:** 검정·회색·흰색·RGB·따뜻한 안료색 등 12색을 원본·반전·흑백·복원 4상태로 검사했습니다. 통제된 불투명 점 중심의 RGB 바이트 최대 오차가 0이었습니다.
- **내장 10점:** 중립 표시 기본값, 유한한 점 데이터, 각 작품의 점 471개에 대한 원본 RGB 지도 대조, 렌더링과 WebGL 오류 0을 확인했습니다.
- **실제 컨트롤:** 색 반전·WB·복원·배경 변경 때 점·깊이·캐시 유지, 밀집도 100%→0%→100%, 양축 360° 이상 드래그와 확대에서 RGB 유지도 확인했습니다.
- **합성 PNG 업로드 2건:** 효과를 켠 뒤 팔레트 업로드 시 중립 기본값으로 복귀하고, 완전한 검정 입력이 정상적인 검정 점으로 표시되는 것을 확인했습니다. 이 검사는 색상·로더 범위이며 AI 깊이 추론은 의도적으로 건너뛰었습니다. 개인 사진은 쓰지 않았습니다.
- **변경 전후 시각 비교:** `3b08746`의 서당과 같은 입력·시드 47821·정면·기본 점 45,000개로 비교했습니다. 기본 XY 좌표 해시도 일치합니다. 깊이·보간점·불투명도·배경은 의도적으로 달라졌으므로 전체 장면이 동일 조건인 지각 품질 실험으로 취급하지 않습니다.

## 해석의 한계

이 수정은 **점의 색상 경로**를 바로잡은 것입니다. 원본 이미지 전체와 표시 화면이 픽셀 단위로 동일하다는 뜻은 아닙니다. 기존 RGB 지도의 해상도, 점 사이 빈틈, 안티앨리어싱, 겹침·투명도·깊이 투영과 선택 효과는 화면에 영향을 줍니다. 원본의 없어진 세부를 복원하지 않습니다. 검증은 데스크톱 브라우저 기준이며 모바일 실기기 성능, 지각 품질, 실측 3D 정확도와 숨은 면 생성은 별도 과제입니다.
