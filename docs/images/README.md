## gallery-current.webp

- 캡처: 2026-10-22, 공개 배포 bab816b의 금강전도 선택 상태.
- 대상: 메인 갤러리의 실제 WebGL 캔버스. UI·해설·상태 표시를 제외한 요소 캡처이며 픽셀 후처리를 하지 않았다. WebP로 저장했다.
- 조건: 원본 색 기본 표시, 반전·WB·번짐 꺼짐, 작품 정면·모인 상태. 완전한 3D 생성 결과가 아니다.
- 권리: 작품 원본의 출처·권리 표시는 [출처 명세](../../assets/artworks/sources.json)와 [작품 기록](../artworks.md)을 따른다.
- 해석: 감상 예시다. 성능·지각 품질·3D 정확도의 시험 자료가 아니다. 캡처 세션에서 자동 해상도 감소 안내가 관측됐으며, 이를 표준화된 FPS 결과로 사용하지 않는다.
