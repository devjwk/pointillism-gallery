# 프로젝트 방향

2026-10-22 논의를 정리한 제품 방향이다. 구현 상태는 [현황](status.md), 목표 순서는 [로드맵](roadmap.md)에 별도로 기록한다.

## 정체성

**원작의 색·구도·여백을 존중하며 그림 속 공간을 점으로 탐색하는 인터랙티브 갤러리.** 한국 회화를 대표 콘텐츠로 삼고 사진 업로드를 확장 기능으로 둔다. 범용 메시 제작기, 무제한 세계 생성기, 기술 슬라이더 전시가 주된 목적은 아니다.

원작을 실제로 존재했던 하나의 공간으로 복원했다고 주장하지 않는다. 특히 회화의 복수 시점·상징·여백은 사실적인 카메라와 지형으로 강제하면 원작과 충돌할 수 있다. 입체화는 원작을 존중하는 하나의 해석으로 취급한다.

## 목표 감상 흐름 · 미구현 설계

1. 작품을 선택하면 점이 모여 원작이 드러난다.
2. 요소를 선택해 형태·맥락·앞뒤 관계를 살펴본다.
3. 원본 시점과 비교하며 추론된 공간을 탐색한다.
4. 잘못 해석된 요소만 선택적으로 수정하고 만족한 부분은 유지한다.

모이기·흩어지기와 일부 구성요소 탐색은 현재 기능이지만, 전체 흐름과 생성·비교·교정 기능은 완성되지 않았다.

## 화면 역할 · 후속 제안

- **감상 모드:** 작품, 원본 비교, 시점 이동, 초기화를 중심에 둔다. 원본 비교를 포함한 이 모드 분리는 아직 구현하지 않았다.
- **실험 모드:** 점 수·분산·깊이·색·분할과 검증 정보를 노출한다. 기존 고급 설정을 제거하자는 제안은 아니다.
- **독립 검증 도구:** 단위 기하·샘플링·저장과 실패를 확인하는 작업대다. 이 도구의 성공이 메인 갤러리의 품질 검증을 뜻하지 않는다.

## 원작 보존 원칙

원본 RGB와 밝기를 기본으로 둔다. 윤곽 중요도·깊이·색 처리를 구분한다. 인물·사물의 관계와 여백을 우선하며 여백을 반드시 벽·땅·객체로 채우지 않는다. 관찰된 색·윤곽을 참고한 영역과 새로 생성한 부분을 구분한다. 이 구분도 실제 형상의 정답이나 보정된 확률은 아니다.

## 저장소 역할

공개 갤러리에는 실행 코드, 공개 권리 근거가 있는 자산, 공개 가능한 익명 기술 기록을 둔다. 별도 비공개 연구는 고정 조건 실험·방법 비교·결과 보존을 담당한다. 연구 결과를 검증·권리 검토·승인 없이 공개 갤러리의 실적으로 합치거나 복사하지 않는다.

## 비목표와 승인 경계

전면적인 기능 재작성, 새 라이선스 부여, 무조건적인 사실화, 완전한 3D 정확도 보장, 학습·사진 전송·유료 GPU 사용의 자동 승인은 이번 방향에 포함되지 않는다. 현재 2.5D, 미래 생성 3D, 점묘 표현을 화면과 문서에서 구별한다.
