# 서브 검증 도구 · 장면의 결

**[도구 열기](https://devjwk.github.io/pointillism-gallery/tools/scene-validation/)** · [소스와 상세 제약](../tools/scene-validation/README.md) · [기능별 구조](architecture.md)

## 메인 사이트와의 차이

메인 갤러리는 작품 감상이 목적이고, 이 도구는 알고리즘의 중간 결과를 확인하는 실험 공간이다. 사진에서 만든 표면이 타당한지 먼저 보고, 같은 메쉬 위에 점을 배치한 다음 점 예산과 시점을 바꿔 비교한다. 여기서 검증된 기능을 이후 메인 사이트에 반영한다.

현재 사진 변환은 상대 깊이로 만든 **보이는 면의 2.5D 표면**이다. 물체의 뒷면, 가려진 배경, 완전한 360° 장면을 생성하지 않는다. 숨은 면을 생성하는 [일회성 GPU 경로](../pipelines/scene_reconstruction/README.md)는 코드만 준비한 미검증 프로토타입이다.

## 가장 짧은 실행 순서

1. 왼쪽 **저장된 사진을 한 번 변환**에서 파일을 선택한다.
2. **사진 → 보이는 3D 표면 · 전송 없음**을 누른다. JPG/PNG/WebP, 최대 20 MiB이다.
3. 완료 후 오른쪽 **표면**으로 형상과 찢어진 부분을 확인한다. 정면/±30°를 비교한다.
4. **표면 점묘**에서 4,000/8,000/16,000점 등 같은 총 점 예산으로 비교한다. 처음에는 원본 시점 보존과 화면 점 크기 보정을 켜 둔다.
5. **현재 3D 장면 파일 저장**으로 다시 사용할 장면을 저장한다. PNG는 화면 비교용, 검증 JSON은 설정·수치 기록용, PLY는 점 좌표 내보내기다.
6. 다음에는 **저장한 장면 JSON 선택 → 장면 JSON 파일 열기**로 불러온다. 같은 저장 파일의 점묘 비교에는 깊이를 다시 추정할 필요가 없다.

사진 없이 시작하려면 **SYNTHETIC · 구 + 평면 열기**를 누른다. 이는 렌더러 확인용 합성 도형이지, 사진을 3D로 생성한 결과가 아니다.

## 무엇을 확인할 것인가

- **형상:** 정면뿐 아니라 ±30°에서 윤곽, 경계, 빈틈과 늘어짐을 확인한다. 점을 늘려도 잘못된 메쉬는 고쳐지지 않는다.
- **원본 시점:** 참조 사진과 표면·점묘 결과를 비교한다. 사진에서 추정한 카메라와 상대 깊이는 실측값이 아니다.
- **점 배치:** 원본 시점 보존과 표면 면적 균일 방식을 비교한다. 기준 시점에서 잘 보이는 것이 모든 시점의 품질을 보장하지 않는다.
- **재현:** 같은 메쉬·난수 시드·점 예산을 유지한다. 회전은 점을 다시 생성하는 과정이 아니다.
- **숫자의 한계:** 유한 좌표·정확한 점 수·점 고정은 구조 검증이다. 시각 품질, 물체 정답 형상, 학술적 우수성이나 성능을 입증하지 않는다.

기존 갤러리의 점 개수 슬라이더는 보간·윤곽 점을 포함한 최종 렌더링 수와 다를 수 있다. 두 구현을 공정하게 비교하려면 최종 점 수와 입력, 시드, 카메라를 따로 통제해야 한다.

## 로컬 처리와 네트워크

- 사진은 브라우저 메모리에서 처리한다. 최초에는 버전 고정 Three.js, Transformers.js와 깊이 모델을 인터넷에서 내려받는다. 따라서 첫 실행까지 완전히 오프라인이라는 뜻은 아니다.
- 저장한 장면은 로컬 파일로 읽는다. 외부 참조 URL과 경로 이탈은 거절하며, 지원되는 정적·비압축 GLB 등 제한된 형식만 허용한다.
- 접힌 원격 API 영역은 향후 별도 서버를 연결하기 위한 예비 인터페이스다. GitHub Pages가 GPU 서버를 제공하지 않는다. 원격 사진 전송에는 서버 지정, 사진 전송 동의와 전송 버튼이 별도로 필요하다.
- 개인 사진·장면 JSON·출력 메쉬·가중치·인증 정보는 공개 저장소에 넣지 않는다. 이 문서에 실제 개인 사진의 변환 결과를 첨부하지 않는다.

## 실행 검증 범위

JS 테스트는 샘플러, 가시면 기하, 로컬 파일 안전성, 리포트와 하위 경로를 검사한다. 브라우저 합성 도형 검사는 렌더링·시점·파일 불러오기 동작을 확인한다. 기존 로컬 사진 실험은 보이는 면의 변환·저장·점묘 비교까지만 확인했다. 새 GPU 3D 생성, 뒷면 추정의 정확성, 모바일 실기기 성능과 전체 모델 연동은 검증하지 않았다.

출처와 사용 조건은 [모델·라이브러리 경계](model-sources.md)를 참고한다.
