# 과거 문서·소개 이미지

현행 방향은 [제품 방향](../project-direction.md), 순위는 [로드맵](../roadmap.md), 실제 구현은 [현황](../status.md)을 기준으로 읽는다. 이 폴더는 과거 표현을 현재 기능이나 확정 계획으로 오해하지 않도록 분리한 보관 영역이다.

- [정리 직전 README](readme-before-direction.md): bab816b의 본문을 보관하고 상대 링크만 새 위치에 맞췄다. 당시 설명을 최신 목표로 간주하지 않는다.
- `images/`: 이전 색 기본값의 갤러리 화면, 소개 시안과 구버전 현황·로드맵. 파일 바이트는 변경하지 않고 옮겼다.
- `images/progress/status-overview.*`의 4점/29개와 `images/progress/roadmap.*`의 순서는 과거 스냅샷이다.

실제 측정 근거인 참조 시점 그래프와 합성 검증 도구 이미지는 현행 `docs/images/`에 남긴다. 이전 본문과 소스는 Git 이력의 bab816b에서도 확인할 수 있다.
