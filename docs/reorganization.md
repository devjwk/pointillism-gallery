# 문서·디렉터리 정리 기록

## 범위 · 2026-10-22

기준은 공개 main의 bab816b다. README를 감상 중심 소개·현재 기능·미래 순위·실행의 입구로 줄이고, 상세 현황·제품 방향·로드맵·레퍼런스·문서 색인을 분리했다. 구버전 이미지와 이전 README는 삭제 대신 아카이브로 보존한다.

실행 진입점, 기능별 소스, 번들, 작품 원본·지도, 검증 도구, GPU 프로토타입, 원시 측정 기록과 기존 테스트는 변경하지 않는다. 계획 문서를 추가한 것이 감상/실험 모드나 생성·학습·교정 기능을 구현한 것은 아니다.

## 보존·검사

- 이전 이미지 19개는 아래 경로로 이동한다. 내용은 동일해야 한다.
- 이전 README는 아카이브에 두되 상대 링크만 새 위치에 맞춘다.
- 현재 공개 작품의 캔버스 캡처 1개와 캡처 조건을 추가한다. 개인 사진은 포함하지 않는다.
- 새 로드맵은 일정·학습·외부 전송·GPU 비용을 승인하지 않는다.
- 비공개 연구 결과·코드·입력은 이 저장소로 복사하지 않는다.
- 게시 전 링크·개인 경로·출력·모델 파일·자격 증명 가드, JS·Python CLI와 실행 자산 바이트 동일성을 확인한다. 현 정리의 실행 로그는 저장소 밖 작업 기록으로 보관한다.
