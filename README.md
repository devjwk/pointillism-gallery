# 점묘 명화 갤러리 (Pointillism Gallery)

한국 명화와 사진을 수만 개의 점으로 흩뿌렸다가 모아서 3D로 보여주는 인터랙티브 뷰어입니다.
점 하나하나가 원본의 밝기, 색, 깊이, 윤곽선을 따라 움직입니다.

**바로 보기: https://devjwk.github.io/pointillism-gallery/**

로그인이나 설치 없이 브라우저에서 열립니다. 파일은 `index.html` 하나뿐이고 서버가 필요 없습니다.

## 들어 있는 작품

| 작품 | 작가 | 비고 |
|---|---|---|
| 인왕제색도 | 정선 (1751) | 조선시대 작품, Wikimedia Commons (퍼블릭 도메인) |
| 미인도 | 신윤복 | 조선시대 작품, Wikimedia Commons (퍼블릭 도메인) |
| 씨름 | 김홍도 | 조선시대 작품, Wikimedia Commons (퍼블릭 도메인) |
| 예시 사진 | Porsche 914 | 제가 직접 찍은 사진 |

내 이미지도 불러올 수 있습니다. 이미지는 서버로 올라가지 않고 내 브라우저 안에서만 처리됩니다.

## 주요 기능

- **점묘 3D**: 점이 흩어졌다가 모이고, 작품 사이를 이동할 때는 같은 점들이 다른 그림으로 변형됩니다.
- **깊이 추정**: AI가 추정한 깊이에 그림 단서(명암, 필치)를 합쳐 입체감을 만듭니다.
- **선 분석**: 윤곽과 필치를 따로 추출해 점 밀도와 윤곽선 점에 반영하고, 디테일이 많은 영역은 눌러서 확대할 수 있습니다.
- **구성요소 인식**: 작품 속 피사체(예: 치마, 저고리, 소나무 숲)를 나눠서 마우스를 올리면 강조하고, 클릭하면 고정합니다. 층 분리와 객체 일체화로 앞뒤 간격을 조절합니다.
- **RGB 색**: 원본 색을 점에 입히고, 색 반영, 색 보정(종이와 조명색 빼기), 채도, RGB 분리(색수차)를 조절합니다.
- **조절 슬라이더**: 점 개수, 대비, 감마, 점 크기, 입체감, 초점 흐림, 번짐 등.

## PC와 모바일 최적화

기기는 자동으로 구분합니다. 주소 뒤에 `?view=pc` 또는 `?view=mobile`을 붙이면 직접 고를 수 있습니다.

| | PC | 모바일 |
|---|---|---|
| 레이아웃 | 사이드바 + 큰 화면 | 그림 위, 하단 시트(작품, 구성요소, 조정, 도구 탭) |
| 점 개수 기본값 | 45,000 (최대 80,000) | 22,000, 저사양 14,000 (최대 40,000) |
| 해상도 상한 | 2배 | 1.75배 |

두 환경 모두 화면이 약 2초 이상 30fps 아래로 느려지면 해상도를 먼저 낮추고, 그래도 느리면 점 개수를 줄입니다.
모바일에서는 무거운 작업(내 이미지 깊이 추정, 구성요소 분석)을 시작하기 전에 확인창을 띄웁니다.

## 기술 구성

- 빌드 도구 없는 단일 HTML 파일 (바닐라 JavaScript + WebGL)
- 점 이동, 3D 투영, 초점 흐림, 마우스 반응은 GPU 셰이더에서 계산
- 작품의 밝기, 깊이, 색, 영역 지도는 파일 안에 압축(gzip + base64)해서 내장
- 선 분석: 다중 스케일 DoG + Sobel, 히스테리시스, 세선화
- 깊이 추정: [Depth Anything V2 (small)](https://huggingface.co/onnx-community/depth-anything-v2-small), 구성요소 분석: [SlimSAM](https://huggingface.co/Xenova/slimsam-77-uniform)
- 두 모델은 [transformers.js](https://github.com/huggingface/transformers.js)로 브라우저에서 실행합니다. 내 이미지를 올릴 때만 필요하고, 모델은 처음에 인터넷에서 내려받습니다.

## 알려진 한계

- 얼굴 같은 세부는 원본 해상도에 좌우됩니다. 미인도 원본은 가로 400px라 이목구비를 사진처럼 복원하지 못합니다.
- 깊이 모델은 사진으로 학습돼서 그림에서는 약합니다. 그래서 명암과 필치 단서를 보조로 합성합니다.
- 내가 올린 이미지는 구성요소 이름을 자동으로 붙이지 못합니다. "피사체 N"으로 표시되고, 더블클릭으로 이름을 바꿀 수 있습니다. 맥락 해설은 내장 작품에만 있습니다.
- 가려진 면(뒷면)은 복원하지 않습니다.
- 모바일 실기기에서는 아직 충분히 검증하지 못했습니다.
- 모바일에서 구성요소 분석(SAM)은 1~3분 걸리고 메모리를 많이 씁니다. PC를 권장합니다.

## 이미지 출처와 저작권

- 인왕제색도, 미인도, 씨름: Wikimedia Commons의 퍼블릭 도메인 이미지입니다.
- 예시 사진: 저작자가 직접 촬영했습니다.
- 이 저장소에는 아직 별도 라이선스 파일이 없습니다. 코드를 재사용하려면 먼저 문의해 주세요.

## 로컬에서 실행

`index.html`을 브라우저로 직접 열어도 되지만, 모델을 불러오는 기능은 로컬 서버에서 더 안정적입니다.

```bash
python3 -m http.server 8000
# http://localhost:8000/ 접속
```

## 수정과 배포

GitHub Pages가 `main` 브랜치의 `index.html`을 그대로 게시합니다. 파일을 교체해서 커밋하면 1~2분 안에 반영됩니다.
